# V5：前三步物理条件与独立累计确认（2026-10-22）

按用户最新定义同步三份 pipette TOML 与系统 prompt：

- Phase 1：移液器已被夹爪拿住、不再由支架支撑，即完成。
- Phase 2：同一试管已被夹爪拿住、不再由架子或原支撑承重，即完成。
- Phase 3：移液器尖端位于所持试管口上方并对准，即完成。

上述三步都不需要等待静止、继续移动结束或下一步开始。第三步也不要求插入、按压、液体转移。
系统 prompt 明确禁止“证据已经说拿起离架，但因为还在移动而输出 in_progress”的矛盾。

控制器现在对每个阶段独立累计高置信度 completed 判断。普通配置的两次确认要求保留，
但不再要求相邻：切换阶段、运动、遮挡、低置信度或后端错误不清空已有计数，也不新增确认。
明确 failed 清空对应阶段的待确认计数；仅高置信度 failed 撤销已接受完成。reset 清空全部状态。
新增输出 phase_confirmation_counts。没有用自然语言关键词强行把模型证据转成成功。

## 验证

30 项 unittest 通过，mock replay 和 diff 空白检查通过。新增用例覆盖交错阶段、遮挡、
后端错误、失败只清除对应阶段、reset 隔离。阶段切换本身仍不能补证前一步成功。

反事实检查：保持 V4 failure_05 的模型输出完全不变，只用新计数逻辑重放，Phase 1 在
18 秒即可确认，而旧逻辑需 21 秒（14、18 秒的 completed 不再因中间阶段变化而清零）。

实际 Qwen/Qwen3.8-27B 回放：1 Hz 抽帧、448px、history=1、初始参考图、两个 episode 并发，
共 86 次调用，平均 4945.5 ms/次。真实模型输出并非与上一版逐帧一致，不能将变化只归因于计数。

结构化物理检查点接口，也没有重测其余八个样本。
